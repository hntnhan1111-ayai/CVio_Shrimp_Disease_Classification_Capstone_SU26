## METHOD 2: Color Normalization - Reinhard

### Overview
Fast color normalization via Lab color space mean/std matching.

### Implementation (Step-by-Step)

**Step 1**: Create preprocessing function
\\\python
import cv2
import numpy as np

def reinhard_normalize(img, reference_mean=None, reference_std=None):
    '''Reinhard color normalization in Lab space'''
    # Default reference: standard Lab values
    if reference_mean is None:
        reference_mean = np.array([50.0, 0.0, 0.0])
    if reference_std is None:
        reference_std = np.array([20.0, 10.0, 10.0])
    
    # Convert to Lab
    img_lab = cv2.cvtColor(img, cv2.COLOR_RGB2LAB).astype(np.float32)
    
    # Compute statistics
    img_mean = np.mean(img_lab, axis=(0, 1))
    img_std = np.std(img_lab, axis=(0, 1))
    
    # Normalize
    normalized = ((img_lab - img_mean) / (img_std + 1e-6)) * reference_std + reference_mean
    
    # Clip and convert back
    normalized = np.clip(normalized, 0, 255).astype(np.uint8)
    return cv2.cvtColor(normalized, cv2.COLOR_LAB2RGB)
\\\

## METHOD 3: Color Normalization - Macenko

### Overview
Medical gold standard; normalizes stain matrix.

### Installation
\\\ash
pip install stain-tools
\\\

### Implementation
\\\python
from stain_tools import StainNormalizer
import cv2

# Fit normalizer on first training image or average
normalizer = StainNormalizer(method='macenko')
normalizer.fit(reference_image)  # reference: uint8 RGB image

def macenko_normalize_batch(images):
    '''Apply Macenko normalization to batch'''
    normalized = []
    for img in images:
        norm_img = normalizer.transform(img)
        normalized.append(norm_img)
    return np.array(normalized)
\\\

### Application
- Apply during training data loading
- Or preprocess dataset once before training

### Expected Outcome
mAP50: 0.512 → 0.534-0.562 (+0.022 to +0.050)

### Success Metric
- Δ mAP50 ≥ +0.020

### Trade-off: Reinhard vs Macenko
- **Reinhard**: Faster, simpler, 80% of Macenko benefit
- **Macenko**: More sophisticated, medical standard, potentially +0.01-0.02 extra gain
- **Recommendation**: Test both in parallel; keep faster method if similar results

## METHOD 4: Learnable CLAHE

### Overview
Contrast-Limited Adaptive Histogram Equalization with random parameters.

### Implementation
\\\python
import cv2
import random
import numpy as np

class CLAHEAugmenter:
    '''Learnable CLAHE augmentation'''
    
    def __init__(self, p=0.5):
        self.p = p
        self.clip_limits = [2.0, 4.0, 8.0]
        self.tile_sizes = [8, 16, 32]
    
    def __call__(self, image):
        if random.random() > self.p:
            return image
        
        clip_limit = random.choice(self.clip_limits)
        tile_size = random.choice(self.tile_sizes)
        
        # Apply CLAHE to L channel (Lab)
        lab = cv2.cvtColor(image, cv2.COLOR_RGB2LAB)
        l_channel = lab[:, :, 0]
        
        clahe = cv2.createCLAHE(
            clipLimit=clip_limit,
            tileGridSize=(tile_size, tile_size)
        )
        l_channel = clahe.apply(l_channel)
        lab[:, :, 0] = l_channel
        
        return cv2.cvtColor(lab, cv2.COLOR_LAB2RGB)

# Usage in data loader
clahe_augmenter = CLAHEAugmenter(p=0.5)
augmented_img = clahe_augmenter(training_image)

## TROUBLESHOOTING

### If CLAHE causes artifacts
- Reduce clip_limit to 2.0
- Reduce tile_size to 8 or 16
- Lower probability to 0.3

### If Copy-Paste increases Healthy FP
- Reduce copy_paste value (e.g., 0.5 → 0.3)
- Or drop method; focus on color normalization instead

### If RandAugment shows no gain
- Try auto_augment='augmax' instead
- Or combine with other methods (e.g., RandAugment + Macenko)

### If results are inconsistent
- Verify random seed is fixed (seed=42)
- Check that grouped-split manifest is deterministic
- Ensure no data leakage between train/val/test
