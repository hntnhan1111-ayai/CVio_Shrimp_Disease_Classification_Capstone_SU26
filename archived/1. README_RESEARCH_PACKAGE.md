### 1. Segmentation Augmentation is Different
- ❌ Don't use classification augmentation (Mixup, CutMix)
- ✅ Do use segmentation-safe (MaskMix, GridMask, YOLO native)

### 2. Color Preprocessing is High-ROI for Biological Images
- ❌ Don't skip color normalization
- ✅ Do use medical-grade (Macenko or Reinhard)

- ❌ Don't apply aggressive augmentation (disease features hidden)

- ❌ Don't assume you need custom augmentation
