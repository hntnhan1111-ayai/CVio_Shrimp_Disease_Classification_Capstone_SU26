This package contains:
- EDA tables, figures, report, and contact-sheet galleries.
- YOLO benchmark summary tables and error logs.
- Lightweight run metadata and plots when available.
- Notebooks used for EDA and YOLO benchmarking.

Excluded intentionally:
- Raw dataset images.
- Converted YOLO dataset images/labels.
- Model weights/checkpoints.
- Exported model files: ONNX, TensorRT, TFLite, OpenVINO, NCNN.
- Individual full overlay image dump if too large.
