# CVio Color System

| Token | HEX | Use |
|---|---|---|
| Deep Navy | `#071A2B` | Primary canvas |
| Ocean Blue | `#0B4F6C` | Secondary surfaces |
| Cyan | `#14B8C4` | Classification and focus cues |
| Teal | `#0F9D8A` | Verified or forward-flow cues |
| Coral | `#FF6B6B` | Shrimp identity and anomaly cues |
| Sand | `#F5E9D3` | High-contrast foreground |
| Amber | `#F6C453` | Pending and caution cues |

Sand on Deep Navy is the primary text pairing. Cyan, Teal, Coral, and Amber are accents, not body-text colors. SVGs use text large enough for their intended display size and retain semantic `<title>` and `<desc>` elements. The hero uses a self-contained dark canvas so it remains stable in GitHub light and dark themes.
