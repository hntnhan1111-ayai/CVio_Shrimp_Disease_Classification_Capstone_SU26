# Pixel Shrimp Source

`sprite-sheet.png` contains all 36 frames of the original CVio animation. Regenerate it and the optimized GIF with:

```powershell
python scripts/docs/generate_shrimp_gif.py
```

The animation uses a theme-safe opaque background, a 3.24-second loop, 11.1 frames per second, 64-color adaptive palettes, and no flashing or audio.
