# Metric reporting

Raw files use decimals in `[0,1]`. Public tables convert them to percentages.

`0.160365 → 16.0365%`

A direct difference is a percentage-point change:

`16.036% − 12.900% = +3.136 pp`

Relative improvement divides the change by the baseline:

`(16.036 − 12.900) / 12.900 × 100 = +24.31%`
