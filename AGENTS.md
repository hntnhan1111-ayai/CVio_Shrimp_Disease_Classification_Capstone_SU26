## Planning and interview rule

For ambiguous, large, research-code, notebook-refactor, or experiment-design tasks:
- Use /plan first.
- Prefer $grill-me before implementation.
- Inspect the real repository/files before asking questions.
- Ask one question at a time only when the answer cannot be found from the codebase.
- Do not edit code until the user approves the plan.
- Write or update PLAN.md before implementation.
