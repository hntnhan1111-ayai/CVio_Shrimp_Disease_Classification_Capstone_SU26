# CVio Final Report — repository instructions

## Goal
Build one integrated FPT Final Report as maintainable native XeLaTeX.

## Read first
Before report work, read the handoff path in `.cvio_handoff_path`, then the report/context/validation specs referenced there.

## Non-negotiable
- FPT A4 one-column thesis layout; never IEEEtran two-column.
- IEEE-quality technical prose/math/references where compatible.
- Times New Roman main text; Times-compatible math.
- Never fabricate evidence.
- Main agent is the only report writer; subagents review.
- Work Chapter VI section-by-section first.
- Every accepted section/chapter must pass strict validation before commit.
- Push every accepted checkpoint.
- Any validation failure => auto-fix, rebuild, rerun.
- Final DONE requires zero unresolved validation findings.
- Never force-push.
- Never edit/reset the dirty original checkout; use the report worktree.
