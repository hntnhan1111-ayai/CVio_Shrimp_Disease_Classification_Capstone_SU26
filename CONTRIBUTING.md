# Contributing

1. Create a focused branch.
2. Do not modify locked checkpoints without recording a new SHA-256.
3. Do not use the test split to tune architecture or hyperparameters.
4. Preserve the exact baseline/model pairing for robustness comparisons.
5. Add raw numeric output and a percentage-formatted public table for each new experiment.
6. Run `python scripts/verify_repository.py` before submitting changes.
