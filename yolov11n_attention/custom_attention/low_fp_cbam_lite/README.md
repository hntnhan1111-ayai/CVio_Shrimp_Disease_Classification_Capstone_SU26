# Low-FP CBAM-Lite

This is a legacy custom-attention experiment folder that existed before the new priority suite generated from `attention_custom_module_proposals.md`.

## Files

- YAML files: `yolov11n_low_fp_cbam_lite.yaml`
- Notebook files: `low_fp_cbam_lite.ipynb`
- Notes: `notes.md` if present

## Status

Preserved for reference and comparison with previous custom attention runs. The new standardized sanity-check system uses folders that contain `model.yaml` and shared code under `custom_attention/_shared/`.

## Caution

Do not assume this legacy folder follows the new `_shared` register/sanity pipeline unless it is explicitly migrated to `model.yaml` and rechecked.
