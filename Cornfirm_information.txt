1, 2. Module cao nhất hiện tại là CA=>SimAm đặt ở P3/P4/P5 trước segment head

các module khác thuộc ablation study và thực nghiệm trên các module khác nhau. Lưu ý DPCA và CoteBoundary Lite là 2 module mới hoàn toàn:
- DPCA là module tôi tạo ra đặt ở P3/P4/P5 trước segment head
x [B,C,H,W]
 ├─ AvgPool 5×5 → local context
 ├─ deviation = x − context
 ├─ bright = ReLU(deviation)
 ├─ dark   = ReLU(−deviation)
 ├─ selector: grouped 1×1 Conv + sigmoid
 │    → chọn trọng số bright/dark cho từng kênh, từng vị trí
 ├─ evidence = w·bright + (1−w)·dark
 ├─ depthwise 3×3 Conv + sigmoid → gate
 └─ y = x + γ·x·(gate − 0.5)
- CoteBoundary Lite là module kết hợp giữa TripletLiteGate và ECA đặt ở P4 segment head kết hợp BoundaryLite Là loss phụ cho biên mask, không phải attention block
P4 feature x
 ├─ TripletLiteGate (k=5)
 │    ├─ nhánh H-W
 │    ├─ nhánh C-W
 │    └─ nhánh H-C
 ├─ ECA channel attention (k=3)
 ├─ disagreement = AvgPool3×3(|triplet − eca|)
 ├─ gate = sigmoid(λt·triplet + λc·eca − α·disagreement)
 └─ y = x + γ·x·gate

6. Loại kết quả được sử dụng 
Chốt cho bảng chính: **chỉ dùng held-out test results**, không dùng final-epoch validation result.

Mỗi run chính thức dùng:

- `best.pt`: checkpoint được chọn trên validation.
- **Held-out full-test result**: mAP trên toàn bộ test set 129 ảnh.
- **Held-out diseased-only test result**: mAP trên 88 ảnh có bệnh.
- Healthy-FP: tính trên 41 ảnh healthy của held-out test.
- Kết quả hiện tại là **fixed-seed (`seed=42`)**, không phải mean ± std multi-seed.

Không dùng trong bảng xếp hạng chính:

- Best validation result: chỉ để chọn checkpoint/run.
- Final-epoch validation result: chỉ để theo dõi overfitting; không đại diện model tốt nhất.
- `last.pt`: không dùng để báo cáo.

Chưa có kết quả hợp lệ dạng **mean ± standard deviation qua 3 seeds**. Khi chạy multi-seed, bảng chính nên thay bằng `mean ± std` trên held-out test, vẫn tách riêng full-test, diseased-only test và healthy-FP.
