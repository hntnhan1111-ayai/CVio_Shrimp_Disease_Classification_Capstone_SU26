# License Status

No source-code license was present on `main` at the start of this repository transformation. No license has been guessed or added on behalf of the maintainers.

Until a license is selected and committed:

- default copyright restrictions apply to source, documentation, and original visual assets;
- repository visibility or clone access does not grant reuse, modification, or redistribution rights;
- dataset, annotation, model-weight, framework, font, and third-party asset terms remain separate;
- contributors should not add incompatible third-party material.

Maintainers should choose a license with project owners and institutional supervisors, then add a standard `LICENSE` file and update `README.md`, `CITATION.cff`, the asset inventory, and dataset cards.
